## 停止与恢复

正常情况下至少持续 5 小时，之后可在独立验收项与收尾完成的节点结束。
8 小时截止、主额度剩余低于 5%、额度真实重置／到达初始窗口截止时间或用户要求停止，任一成立即停止开发。
每步开始、验证后、提交前和长任务间隙检查额度；持续查询失败则停止，不盲跑。
不把初始满额或重置时间秒级抖动当作重置；不购买额度、不用重置券、不切换额度池绕过限制。
权限或范围阻塞先做安全的在范围内排查，确需用户决定时报告。

触发停止后只做必要进程清理和最小记录，未验收内容保留工作区，不补做功能凑提交。
已授权在上述条件满足时暂停目标；未完成业务目标不标为完成，恢复需明确授权。
不通过等待、重复测试或无消费者 API 凑时长；范围内有效工作提前全部完成则如实报告。
