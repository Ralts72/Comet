# 054 输入与脚本工作流收尾审查

## 本项是什么

044–053 已完成运行相机捕获、持续轴转向、demo 手柄绑定、玩家来源切换修复，以及外部脚本编辑入口。
本项补全套回归和实际桌面证据，并复核新增职责；没有新增 Manager、生产测试入口或运行时功能。

## 架构复核

| 层次 | 当前边界 | 本次复核结论 |
| --- | --- | --- |
| System／Runtime | 控制器表达捕获意图，Runtime 根据状态及本帧授权过滤 | 不缓存上一帧捕获结果；准备标志只防止读取过期输入 |
| Engine／Window | 唯一原生光标执行点，负责退出／失焦等释放 | 不向 Scene 暴露 GLFW，不给 App／Editor 各写一套设备控制 |
| ImGui／Viewport | UI 鼠标交接与画面授权 | 不拥有 Runtime 状态，不重新解释相机动作绑定 |
| PlayerInputPanel | 草稿、录入与错误展示 | 不保存玩家文件、不重启 Lua；来源切换不是恢复个人历史 |
| App／Editor | 保存结果、运行边界应用和重开 | 各自保留运行副本／Edit 生命周期；共享文件和映射规则，不为短编排再套 façade |
| ProjectPanel／SourceOperations | 源码打开请求、项目路径校验 | 不把“打开”当导入或 Undo，不解析坏 Lua 才允许修复 |
| SystemTextEditor | Editor 私有的无状态平台交付 | 不塞进 Engine 或回收站接口，不引入通用 FileSystem |
| Script | 同一准备快照与纯文本解析入口 | BOM 只调整解析视图，原始大小、版本比较、旧实例源快照保持 |

051 的长用例只承担跨模块状态契约，仍使用真实 demo Lua、面板、个人文件和 Runtime；
没有复制一套 System 或渲染器。053 两项测试分别覆盖文本可用性与快照／行号，不增加平行夹具。
本轮未发现需要额外拆类或合并 owner 的阻塞问题。目录和 README／架构文档仍按用法、职责、历史分别记录。

## macOS 外部源码的实际证据

通过临时可执行入口链接**当前生产实现** `SystemTextEditor::open`，而不是复制一份打开命令：

```text
生产 open(path)
  → 系统文本编辑器显示 Comet source 源码.lua
  → 将 speed 7 改为 9 并保存
  → 文件读取确认保存结果
```

入口和源码位于 `/tmp/comet-text-editor-smoke.tcgMWS`，不进入仓库。
验证覆盖带空格和中文的文件名，返回成功后确实看到指定文件及内容；不只凭启动器退出码宣布完成。

随后在隔离项目启动真实 Editor，以同一入口打开 `spin.lua`，通过文本编辑器把 `speed = 100`
临时改成 `speed =` 并保存。10:48:24 的现有文件日志记录：

```text
Cannot refresh script group containing …:
@scripts/spin.lua: scripts/spin.lua:10: unexpected symbol near ','
```

这证明外部保存通过既有源文件监测进入脚本组刷新及错误反馈；画面保持、Editor 未退出。
之后保存恢复的源码，关闭两个临时文档和 Editor；脚本字节与备份一致，`.meta` 的 SHA-256 未变。
没有观察到 Play 新实例，因此不把“恢复后没有再报错”当作活动实例替换的正向证明。

为取得证据，第二次启动前短暂开启现有 Debug 文件日志，初始化后立即还原配置；
正常关闭后只撤回验证新增的最近项目条目及所选底部页签，两份用户文件与启动前逐字节一致。
没有保存源项目、改写个人输入文件或留下常驻测试进程。

## App 的可见反馈与限制

本轮在隔离 demo 的真实 App 中，桌面键盘操作确认了以下可见反馈：

- Space 暂停中心方块旋转；Tab 进入调色，方向键使蓝色变为橙色、紫色。
- 调色时左侧移动方块保持原位；Space 确认不同时恢复旋转。
- R 恢复初始颜色并重新旋转。

隔离项目保留相同键盘默认绑定，但并非本轮新增手柄默认绑定的设备验收。
短按方向键没有得到可确认的持续位移，不能据此宣布触发／计分／发声完成或判定普通长按有故障。
App 的 Input 与 Editor 的运行按钮仍遇到自动指针事件位置滞后的限制，未进入完整设置菜单／Play 链路。
不为工具注入增加生产快捷键，不开启已经关闭的 ImGui 方向键导航，也不修改三方输入后端绕过它。
