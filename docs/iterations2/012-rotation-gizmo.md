# 012：旋转 Gizmo 与统一变换交互

## 背景与前后对比

阶段 4 的平移已具备命中、预览、撤销及输入互斥，本项增加可独立验收的旋转，不重建一套手势系统。

| 之前 | 之后 |
| --- | --- |
| TranslationGizmo，仅平移 | TransformGizmo，Move／Rotate 模式 |
| Handle 保存单条起终点 | Handle 保存线段集合：箭头一段，圆环最多 64 段 |
| 鼠标射线与轴求最近参数 | 平移保留原算法；旋转求射线与轴法平面的交点角度 |
| 固定 translation 事务 | 按模式选择 translation／rotation，共用原事务生命周期 |
| Tool 仅空间和距离步长 | 增加模式、角度步长；不增加画面浮层和快捷键 |

文件和 CMake、Editor／ViewPanel／测试引用一起改名；旧迭代文档保留当时名称，不伪造历史。

## 代码级逻辑

`TransformGizmo::Settings` 增加 Mode 和 rotation_step_degrees；原 step 明确为 translation_step。
两类步长分别校验有限且大于零。更换模式／空间／步长仍先取消未完成事务，同值设置不取消。

`make_context()` 保存起点 Euler rotation、父级正逆矩阵，以及用于旋转交互的基：

- World 使用世界单位基；父级线性部分必须是均匀缩放的正交基，可以包含镜像。
- Local 使用 `parent_linear * local_rotation`，按最大列长统一缩放保持显示尺寸；保留仿射形状，不独立归一化三列。
- 不乘实体自己的 scale，因此自身零／负缩放不使手柄退化或反转；不可逆父级仍拒绝交互。

`make_handles()` 在对应轴法平面采样圆环并投影成逻辑屏幕线段，ViewPanel 绘制这些线段，命中也测试同一集合。
射线与平面平行、无法定义角度的边缘环不生成可操作段。拖动期间冻结初始圆环基，避免 Local 环跟随预览旋转造成反馈跳变。

`pointer_ray()` 从布局与逆 VP 生成射线，由平移／旋转共用。`rotation_parameter()` 将射线变换到旋转基，
与选中坐标平面相交，使用另外两轴的 `atan2` 得到角度。圆心角度未定义时取消，不写入 NaN。

`preview_value()` 将相邻角度差通过 `remainder(delta, 2*pi)` 展开后累计，跨越 ±180° 不会突然反转。
Snap 使用 `round(degrees / rotation_step_degrees) * rotation_step_degrees`，始终相对手势起点。
令 `R0` 为初始本地旋转、`D` 为轴角增量、`P` 为父级线性变换：

```cpp
// Local
R = R0 * D;
// World
R = inverse(P) * D * P * R0;
```

结果经过规范化 quaternion 转回当前组件采用的 Euler 度数，仍遵守 `Rz * Ry * Rx` 组合顺序。
接近整圈的零增量直接返回原始 Euler，避免无实际旋转却因表示差异产生空历史。
旋转期间实体位置、父级、相机、布局、选择、文档 generation 或外部 rotation 改变时回退事务；
正常的自身 rotation 预览不触发取消。释放只提交一次，Escape／失焦／隐藏仍走原取消路径。

## 设计理由与架构价值

- 变换交互拥有数学和手势状态，ViewPanel 只绘制、捕获 ImGui 输入；渲染器和 engine 不感知 Gizmo。
- 平移、旋转共用 UUID／generation／PropertyEditTransaction，没有复制历史命令和生命周期判断。
- Handle 的线段集合是显示与命中的共同输入，不让画面上的环与实际命中区域各算一遍不同几何。
- World 非均匀父级限制是当前组件表示能力的边界：共轭变换可能产生剪切，不能只改 rotation 而保持 scale 还宣称精确。
  因此禁用这类 World 环并在 Tool 中说明使用 Local，而不是静默分解或覆盖用户缩放。
- 本次没有新增通用事件总线、模式继承树、engine 包装层，也没有调整 Shader 或第三方代码。

## 测试结果

- Debug／Release 全部构建成功，各 **398 tests** 通过；完整图形测试日志无 VUID／Validation Error。
- 新增 6 个数学／事务测试：两种投影、XYZ 轴与 Euler 奇异姿态的矩阵等价性、Local 非均匀镜像父级、
  World 均匀镜像父级及非均匀拒绝、跨 ±180° 吸附／整圈空历史、模式／位置／角度无定义取消。
- 新增 1 个真实 ImGui 帧测试：旋转环预览、吸附、滚轮所有权、拾取／相机互斥、捕获释放及单条撤销。
  原 Tool 菜单测试同时覆盖 Mode 切换不修改场景。
- UI 首轮测试发现 ImGui 鼠标坐标会取整到逻辑像素，不能把理想浮点圆环角度当作像素输入的精确角度；
  UI 用开启吸附的实际链路断言 45°／90°，无吸附精度由直接浮点输入的数学测试覆盖。
- 既有平移、裁切、DPI、生命周期和场景帧顺序测试保持通过；clang-format／diff 检查通过。
- 010、011 的 Linux CI 已确认成功（34050484992、34050761975）。本项 CI 待推送后确认。
  没有进行桌面人工操作／截图验收，不将自动 ImGui 帧测试描述为人工验证。

## 限制与后续方向

- 一帧指针角度跳跃超过半圈不能恢复真实转向；当前按最短相邻角差处理。圆心／平行环不支持旋转。
- Euler 组件可能出现等价角度表示切换，测试以变换矩阵而不是唯一 Euler 数组判断一般姿态正确性。
- 环为覆盖层，不做场景深度遮挡；64 段为固定采样，不新增采样策略系统。
- 无自由球旋转／屏幕轴旋转，设置只在当前编辑器会话存在；下一独立验收项是缩放及其吸附。
